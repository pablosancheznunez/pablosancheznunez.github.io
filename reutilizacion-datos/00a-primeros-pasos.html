Primeros pasos con R en el navegador

No hace falta saber programar para seguir este libro. Este capítulo enseña lo mínimo para entender y modificar el código de los tutoriales: unos 30 minutos.

R como calculadora

Escribe una operación y pulsa Run Code. R devuelve el resultado precedido de [1] (el número indica la posición del primer valor de la línea).

Objetos: guardar un valor con un nombre

La flecha <- guarda un valor en un objeto. Después puedes usar el nombre en lugar del valor.

Vectores: varios valores del mismo tipo

c() («combinar») crea un vector. Muchas funciones trabajan sobre vectores enteros: sum(), mean(), length(), max()…

Los textos van entre comillas:

Ejercicio 1

Calcula el máximo de préstamos del vector prestamos.

La función se llama igual que en una hoja de cálculo, en minúsculas.

max(prestamos)

Una comparación devuelve TRUE o FALSE para cada elemento. sum() sobre un vector lógico cuenta los TRUE.

Ejercicio 2

¿Cuántos meses tuvieron menos de 2400 préstamos?

sum(prestamos < 2400)

Tablas de datos (data frames)

Un data frame es una tabla: cada columna es un vector. Con $ se accede a una columna.

Para quedarse con algunas filas se usa subset():

Leer un fichero CSV

El CSV de práctica está disponible en la carpeta datos. read.csv() lo convierte en un data frame; head() muestra las primeras filas y str() describe las columnas.

Fíjate en str(): la columna prestamos aparece como chr (texto), no como número. Algo en el fichero impide que R la reconozca como numérica. Lo resolverás en el Tema 3.
