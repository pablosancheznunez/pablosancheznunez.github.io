Apéndice C — Glosario

Términos técnicos del libro, agrupados por tema. Cada capítulo enlaza aquí desde su recuadro «Glosario del tema», y desde cada término puedes volver al capítulo donde se explica. Usa el buscador del libro (arriba a la izquierda) para localizar cualquier término.

Tema 0. Datos abiertos

Datos abiertos

Datos que cualquiera puede usar, modificar y compartir libremente para cualquier fin, con como mucho la obligación de citar la fuente o de compartir en las mismas condiciones. → Tema 0

Open Definition

Definición de «abierto» de la Open Knowledge Foundation (versión 2.1). Exige licencia abierta, acceso completo y formato legible por máquina y abierto. → Tema 0

Datos públicos

Información producida o custodiada por el sector público. No toda es abierta: puede incluir datos personales o protegidos. → Tema 0

Gobierno abierto

Forma de gobernar basada en la transparencia, la participación y la colaboración. Los datos abiertos son una de sus herramientas. → Tema 0

Modelo de cinco estrellas

Escala acumulativa de Tim Berners-Lee para valorar la publicación de datos: de un documento con licencia abierta (★) a datos enlazados (★★★★★). → Tema 0

Principios FAIR

Datos localizables (Findable), accesibles (Accessible), interoperables (Interoperable) y reutilizables (Reusable). No equivale a «abierto». → Tema 0

Formato abierto

Formato con especificación pública que cualquiera puede implementar sin pagar ni pedir permiso (CSV, JSON, XML, ODS). Su contrario es el formato propietario. → Tema 0

Legible por máquina

Formato del que un programa puede extraer los datos sin intervención humana. Un PDF escaneado no lo es; un CSV sí. → Tema 0

Licencia abierta

Licencia que permite usar, redistribuir y modificar para cualquier fin. Puede exigir atribución (CC BY) o compartir igual (CC BY-SA, ODbL), pero no prohibir el uso comercial (NC) ni las obras derivadas (ND). → Tema 0

Web Semántica

Extensión de la Web en la que los datos tienen un significado explícito y enlazado que las máquinas pueden procesar. → Tema 0, Tema 4

Tema 1. Reutilización de la información del sector público

Reutilización

Uso de documentos del sector público con fines comerciales o no comerciales distintos del propósito inicial para el que se produjeron (Ley 37/2007). → Tema 1

RISP

Reutilización de la información del sector público. Nombre del marco normativo europeo y español sobre la materia. → Tema 1

Derecho de acceso

Derecho de cualquier persona a solicitar y conocer la información pública (Ley 19/2013). Es previo a la reutilización, pero no la garantiza. → Tema 1

Publicidad activa

Información que las administraciones deben publicar sin que nadie la pida: organización, contratos, subvenciones, presupuestos. → Tema 1

Silencio administrativo negativo

Si la administración no resuelve en plazo, la solicitud se entiende desestimada. Rige tanto en el derecho de acceso como en las solicitudes de reutilización. → Tema 1

Licencia tipo

Texto de licencia estándar, igual para todos los reutilizadores, publicado en el aviso legal de un portal. → Tema 1

Conjuntos de datos de alto valor

Datos con gran beneficio social y económico, que deben ofrecerse gratis, por API y con licencia abierta. Seis categorías: geoespaciales, observación de la Tierra y medio ambiente, meteorológicos, estadísticos, sociedades y movilidad. → Tema 1

Datos dinámicos

Datos que se actualizan con frecuencia o en tiempo real, como los de tráfico o sensores. Deben ofrecerse mediante API. → Tema 1

Transposición

Incorporación de una directiva europea al derecho de un Estado miembro mediante una norma propia. Los reglamentos, en cambio, se aplican directamente. → Tema 1

Agente infomediario

Reutilizador que crea productos o servicios de valor añadido a partir de información, sobre todo pública. → Tema 1, Tema 5

Tema 2. Proyectos de reutilización

Portal de datos abiertos

Sitio web que cataloga y da acceso a conjuntos de datos abiertos, como datos.gob.es o data.europa.eu. → Tema 2

Federación de catálogos

Recolección automática de los metadatos de varios portales en un catálogo común. datos.gob.es federa portales estatales, autonómicos, locales y universitarios. → Tema 2

Open Data Maturity

Informe anual que compara la madurez en datos abiertos de 36 países europeos en cuatro dimensiones: políticas, impacto, portal y calidad. → Tema 2

Caso de uso

Proyecto concreto que reutiliza datos. Conviene describirlo con las dimensiones de Safarov et al.: tipo de utilización, condiciones, efectos y usuarios. → Tema 2

B2G

Business-to-government: intercambio de datos de empresas con administraciones para fines de interés general. → Tema 2

Altruismo de datos

Cesión voluntaria de datos por ciudadanos o empresas para fines de interés general, regulada por el Reglamento de Gobernanza de Datos. → Tema 2

Ciencia abierta

Práctica de la investigación que hace accesibles publicaciones, datos, código y métodos para que puedan comprobarse y reutilizarse. → Tema 2

Repositorio de datos

Servicio que deposita, describe, preserva y da acceso a conjuntos de datos con un identificador persistente (Zenodo, e-Archivo). re3data es el registro mundial de repositorios. → Tema 2

Data paper

Artículo científico que describe un conjunto de datos —origen, método y estructura— para facilitar su reutilización. → Tema 2

API

Interfaz de programación de aplicaciones: una dirección web que devuelve datos estructurados (normalmente JSON o XML) para que los use un programa, no una persona. datos.gob.es ofrece una para consultar su catálogo. → Tema 2

Tema 3. Gestión documental y open data

Gestión documental

Conjunto de procesos para controlar la creación, clasificación, valoración, conservación y eliminación de documentos (ISO 15489). → Tema 3

Ciclo de vida de los datos

Secuencia de fases por las que pasan los datos, desde su creación hasta su reutilización, preservación o eliminación (modelo del DCC). → Tema 3

Metadatos

Datos que describen otros datos: qué son, quién los publica, con qué licencia, cómo están estructurados y cómo se conservan. → Tema 3

DCAT

Vocabulario del W3C para describir catálogos, conjuntos de datos (dcat:Dataset) y distribuciones (dcat:Distribution). DCAT-AP y DCAT-AP-ES son sus perfiles europeo y español. → Tema 3

Distribución

Cada forma concreta de obtener un conjunto de datos: un fichero CSV, un JSON, una API. → Tema 3

Completitud

Característica de calidad que mide la proporción de celdas o filas sin valores ausentes. → Tema 3

Conformidad

Característica de calidad que mide si los valores siguen el formato esperado (fechas, códigos, unidades). → Tema 3

Exactitud

Característica de calidad que mide si los valores son correctos y plausibles. Un número de préstamos negativo es un error de exactitud. → Tema 3

Valor ausente

Celda sin dato. En R se representa con NA; en los ficheros aparece de muchas formas («», «n/d», «-»), lo que conviene unificar. → Tema 3

Suma de control (checksum)

Huella numérica de un fichero (MD5, SHA-256) que permite comprobar que no ha cambiado ni se ha corrompido. → Tema 3

OAIS

Modelo de referencia para archivos digitales que deben preservar información a largo plazo (ISO 14721). → Tema 3

Identificador persistente

Identificador que no cambia aunque cambie la ubicación del recurso, como un DOI, un ORCID o un Handle. → Tema 3

Tema 4. Normalización e interoperabilidad

Estándar abierto

Especificación pública, desarrollada en un proceso abierto e implementable sin pagar derechos. → Tema 4

Interoperabilidad

Capacidad de sistemas y organizaciones para intercambiar información y usarla. El EIF distingue cuatro niveles: jurídico, organizativo, semántico y técnico. → Tema 4

ENI

Esquema Nacional de Interoperabilidad: criterios que deben seguir las administraciones españolas para que sus sistemas interoperen. Se desarrolla en Normas Técnicas de Interoperabilidad (NTI). → Tema 4

URI

Identificador uniforme de recursos: cadena que identifica algo de forma única en la Web, como http://www.wikidata.org/entity/Q8802. → Tema 4

RDF

Modelo del W3C que representa la información como tripletas sujeto–predicado–objeto. Se escribe en sintaxis como Turtle, RDF/XML o JSON-LD. → Tema 4

Tripleta

Unidad mínima de RDF: un sujeto, un predicado y un objeto, por ejemplo «biblioteca — está en — Getafe». → Tema 4

Turtle

Sintaxis compacta y legible de RDF, con prefijos para abreviar las URI. → Tema 4

JSON-LD

JSON con un @context que asigna a cada clave una URI de un vocabulario: RDF con aspecto de JSON. → Tema 4

Linked Open Data

Datos enlazados publicados con licencia abierta: las cinco estrellas del modelo de Berners-Lee. → Tema 4

SPARQL

Lenguaje de consulta del W3C para datos RDF, basado en patrones de tripletas. → Tema 4

Vocabulario

Conjunto de clases y propiedades con URI para describir datos (schema.org, Dublin Core, DCAT). → Tema 4

Ontología

Vocabulario con una semántica formal más rica (jerarquías, restricciones, reglas de inferencia), expresado en RDFS u OWL. → Tema 4

SKOS

Vocabulario del W3C para publicar tesauros y clasificaciones en la Web, con relaciones como skos:broader y skos:narrower. → Tema 4

Tipo MIME

Etiqueta normalizada que indica el formato de un fichero en internet, como text/csv o application/json. Convive en los catálogos con el vocabulario de tipos de fichero de la UE, lo que obliga a normalizar. → Tema 2, Tema 4

Tema 5. Infomediarios y negocio

Sector infomediario

Conjunto de empresas que crean productos y servicios de valor añadido a partir de información, en buena parte pública. → Tema 5

Marco 6-V

Seis componentes para describir cómo un negocio crea y captura valor con datos abiertos: propuesta de valor, proceso de creación, valor obtenido, captura, gestión y red de valor (Ahmadi Zeleti et al.). → Tema 5

Freemium

Modelo de negocio con un servicio básico gratuito y funciones avanzadas de pago. → Tema 5

Punto de equilibrio

Volumen de actividad a partir del cual los ingresos cubren los costes. → Tema 5

Servicio de valor añadido

Producto que transforma los datos en algo más útil: agregación, limpieza, enriquecimiento, análisis, visualización o API. → Tema 5

Compartir igual (share-alike)

Cláusula de licencia que obliga a distribuir las obras o bases de datos derivadas con la misma licencia (CC BY-SA, ODbL). → Tema 5

Minería de textos y datos

Análisis automatizado de textos y datos para extraer patrones. La Directiva (UE) 2019/790 regula sus excepciones de derechos de autor. → Tema 5

Espacio de datos

Entorno de confianza para compartir datos, también privados, entre organizaciones de un sector con reglas comunes. → Tema 5

Datos sintéticos

Datos generados artificialmente que imitan la estructura de los reales sin corresponder a casos reales. El CSV de este libro es un ejemplo. → Tema 5

Herramientas

R

Lenguaje y entorno libre para análisis estadístico y de datos. → Primeros pasos

webR

Versión de R compilada a WebAssembly que se ejecuta en el navegador, sin instalación. → Presentación

Quarto

Sistema de publicación científica de código abierto que combina texto y código para generar libros, artículos, presentaciones y webs. → Presentación

Data frame

Tabla de datos en R: cada columna es un vector del mismo tamaño. → Primeros pasos

OpenRefine

Herramienta libre para limpiar y transformar datos, con agrupación (clustering) de valores similares. → Tema 3

Paquete de R

Conjunto de funciones, datos y documentación de R que se instala y se carga con library(). El paquete datareuseR reúne las funciones y los datos de este libro. → Apéndice A

Service worker

Programa que el navegador ejecuta en segundo plano para una web. En este libro guarda las páginas y el motor de R para que funcionen sin conexión después de la primera visita. → Presentación
