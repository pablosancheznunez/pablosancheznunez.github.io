Apéndice B — Laboratorio interactivo

Este apéndice reúne un laboratorio y un escenario ramificado para practicar en tu navegador.

Laboratorio: la matriz de Eisenhower

Laboratorio · se ejecuta en tu navegador

Escribe tus tareas de la semana (o usa las de ejemplo) y marca si son urgentes e importantes. La matriz las coloca en su cuadrante y te sugiere qué hacer con cada grupo.

{
  const ejemplo = [["Revisar la versión final del artículo", true, true], ["Responder correos de la lista del departamento", true, false], ["Escribir la introducción del proyecto (convocatoria en 3 meses)", false, true], ["Leer un artículo clave para la tesis", false, true], ["Reunión semanal sin orden del día", true, false], ["Rellenar el informe de seguimiento que vence mañana", true, true], ["Revisar redes sociales académicas", false, false], ["Preparar la formación de la doctoranda nueva", false, true]];
  const raiz = html`<div class="eisen-lab"></div>`;
  const tabla = html`<table class="table table-sm align-middle"><thead><tr><th scope="col">Tarea</th><th scope="col">Urgente</th><th scope="col">Importante</th></tr></thead><tbody></tbody></table>`;
  const filas = ejemplo.map(([t, u, i], k) => { const id = "eh" + k + Math.random().toString(36).slice(2, 6); const tr = html`<tr><td><label class="visually-hidden" for="${id}t">Tarea ${k + 1}</label><input id="${id}t" class="form-control form-control-sm" value="${t}"></td><td><input type="checkbox" class="form-check-input" aria-label="Tarea ${k + 1} urgente" ${u ? "checked" : ""}></td><td><input type="checkbox" class="form-check-input" aria-label="Tarea ${k + 1} importante" ${i ? "checked" : ""}></td></tr>`; tabla.tBodies[0].append(tr); return tr.querySelectorAll("input"); });
  const salida = html`<div role="status" aria-live="polite"></div>`;
  const esc = (s) => s.replace(/[&<>]/g, (c) => ({"&": "&amp;", "<": "&lt;", ">": "&gt;"}[c]));
  const cuad = [["Hacer ya", "Urgente e importante", true, true, "#fde2e1"], ["Planificar", "Importante, no urgente", false, true, "#e2f0e5"], ["Delegar o acotar", "Urgente, no importante", true, false, "#fdf1d8"], ["Eliminar", "Ni urgente ni importante", false, false, "#ebebeb"]];
  function dibujar() {
    const tareas = filas.map(([t, u, i]) => ({t: t.value.trim(), u: u.checked, i: i.checked})).filter((x) => x.t);
    const grupos = cuad.map(([n, desc, u, i, c]) => ({n, desc, c, ts: tareas.filter((x) => x.u === u && x.i === i)}));
    const consejo = grupos[0].ts.length > grupos[1].ts.length ? "Tienes más tareas en «Hacer ya» que en «Planificar»: vives apagando fuegos. Reserva bloques fijos para lo importante antes de que se vuelva urgente." : grupos[1].ts.length ? "Bien: lo importante no urgente tiene espacio. Ponle fecha y hora en tu agenda; si no, lo urgente lo desplazará." : "No tienes tareas importantes a largo plazo: ¿dónde está tu tesis, tu próximo proyecto o tu formación?";
    salida.innerHTML = `<div class="row g-2">${grupos.map((g) => `<div class="col-6"><div class="p-2 rounded h-100" style="background:${g.c};color:#0b0b0b"><strong>${g.n}</strong> <span class="small">(${g.desc})</span><ul class="mb-0 small">${g.ts.map((x) => `<li>${esc(x.t)}</li>`).join("") || "<li><em>ninguna</em></li>"}</ul></div></div>`).join("")}</div><p class="mt-2">${consejo}</p>`;
  }
  filas.forEach((f) => f.forEach((e) => e.addEventListener("input", dibujar)));
  raiz.append(tabla, salida); dibujar();
  return raiz;
}

Laboratorio: tus OKR

Laboratorio · se ejecuta en tu navegador

Los OKR (objetivos y resultados clave) separan adónde quieres ir (un objetivo cualitativo e inspirador) de cómo sabrás que has llegado (dos a cinco resultados medibles con fecha). Escribe los de tu grupo o tu tesis para este semestre.

textoO = window.Lab.texto
areaO = window.Lab.area
viewof objetivo = textoO("Objetivo", {value: "Que nuestro grupo sea referente en ciencia abierta en la universidad"})
viewof krs = areaO("Resultados clave (uno por línea)", {rows: 4, value: "Publicar en abierto los datos de los 3 proyectos activos antes de junio\nMejorar la visibilidad del grupo\nImpartir 2 talleres de reproducibilidad con al menos 40 asistentes en total\nHacer muchas reuniones"})
{
  const ls = krs.split("\n").map((l) => l.trim()).filter(Boolean);
  const esc = (s) => s.replace(/[&<>]/g, (c) => ({"&": "&amp;", "<": "&lt;", ">": "&gt;"}[c]));
  const tareas = /\b(hacer|reuni[oó]n|reuniones|trabajar en|intentar|seguir)\b/i;
  const evalua = (k) => { const num = /\d/.test(k), fecha = /\b(antes de|en|para)\s+(enero|febrero|marzo|abril|mayo|junio|julio|agosto|septiembre|octubre|noviembre|diciembre|el semestre|el curso|20\d\d)|\b(trimestre|semestre)\b/i.test(k), tarea = tareas.test(k);
    const p = []; if (!num) p.push("no es medible: añade una cifra"); if (!fecha) p.push("sin fecha límite"); if (tarea) p.push("describe una actividad, no un resultado");
    return {k, ok: num && !tarea, p}; };
  const res = ls.map(evalua);
  const objAv = [];
  if (/\d/.test(objetivo)) objAv.push("El objetivo lleva cifras: déjalas para los resultados clave y haz el objetivo inspirador.");
  if (objetivo.split(/\s+/).length < 5) objAv.push("El objetivo es muy corto: ¿se entiende sin contexto?");
  if (ls.length < 2 || ls.length > 5) objAv.push(`Tienes ${ls.length} resultados clave: lo habitual son entre 2 y 5.`);
  const d = html`<div role="status" aria-live="polite"></div>`;
  d.innerHTML = `<div class="p-3 border rounded"><div class="small text-body-secondary">Objetivo</div><div class="fs-5 fw-semibold mb-2">${esc(objetivo)}</div><ol class="mb-0">${res.map((r) => `<li>${r.ok ? "✓" : "✗"} ${esc(r.k)}${r.p.length ? `<div class="small text-body-secondary">${r.p.join(" · ")}</div>` : ""}</li>`).join("")}</ol></div>${objAv.length ? `<ul class="mt-2">${objAv.map((a) => `<li>⚠ ${a}</li>`).join("")}</ul>` : ""}<p class="mt-2">${res.filter((r) => r.ok).length} de ${res.length} resultados clave son medibles. Reescribe los marcados con ✗: «Mejorar la visibilidad» podría ser «Duplicar las visitas a la web del grupo antes de diciembre».</p>`;
  return d;
}

Revisa los OKR cada mes. Un resultado clave alcanzado al 70 % suele indicar un objetivo bien calibrado; si siempre llegas al 100 %, eran demasiado fáciles.
