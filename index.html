About

I'm interested in how people behave when using digital products and services, and how we can make them better.

Outside academia, you should know that I love travelling, meeting interesting people, and learning something new every day. I make New Year's resolutions I never keep, always go out of my way for a good curry, and disappear into nature whenever I get the chance.

Research interests

  • Visual communication — how visual choices shape understanding.
  • User experience — designing digital interactions that respect people's time and attention.
  • Digital marketing — how organisations communicate with audiences online.
  • Informetrics — measuring how information moves, spreads and gets used, in academic research and beyond.
  • Open Science — building infrastructure that makes research more transparent and trustworthy.

R packages

Open-source R packages for research and teaching. Each has its documentation website with worked examples.

Digital marketing and consumer research

  • abfunnel

    Design, check and analyse digital marketing experiments (A/B tests) and conversion funnels to research standards: sample size, pre-registration, sample ratio checks and effects with confidence intervals.

    Documentation · Example report · Source code

  • visualbrief

    Turn digital campaign data into clear, reusable visual reports: comparisons across audiences with confidence intervals, accessible branded charts and a self-contained report to share.

    Documentation · Example report · Source code

  • neuroconsumer

    Build the visual stimuli of advertising and consumer experiments from code: declared factors, conditions verified to differ only where intended, deterministic SVG/PNG output and Areas of Interest for eye tracking.

    Documentation · Example stimulus pack · Source code

User experience

  • uxlearn

    Learn and teach user experience research: usability metrics, simulated usability studies, case studies and a workbook.

    Documentation · Source code · DOI

Science communication

  • scicomm

    Check how a scientific result is communicated to specialists, students and the public: what each version keeps, loses or overstates, with clarity, accessibility and uncertainty indicators in English and Spanish.

    Documentation · Example report · Source code

Research integrity and assessment

  • aitrail

    Document, verify and disclose the use of AI in research: a log of AI use in each phase of a project, human verification, an audit of oversight gaps, reference checks and disclosure statements in English and Spanish.

    Documentation · Example report · Source code

  • reproimage

    Integrity, provenance and reproducibility checks for scientific images, in R and Python: finds identical and similar images, including rotated and flipped copies, and records provenance.

    Documentation and example report · Source code · DOI

  • narrativecv

    Map narrative CV sections (Résumé for Researchers, the Spanish CVA) to the evidence ORCID, OpenAlex, DataCite and OpenAIRE hold about a researcher. The R companion of the Narrative CV Crosswalk.

    Documentation · Source code · DOI

  • academiccareer

    Describe how a research career develops over time across outputs, software, data, funding, teaching, supervision, service and knowledge transfer, from ORCID, OpenAlex and DataCite and evidence declared by the researcher. Descriptive profiles, with no ranking or scores.

    Documentation · Example report · Source code

Other projects

Web tools

  • Narrative CV Crosswalk

    An open, versioned map between narrative CV sections and the evidence held in open research infrastructures. Enter an ORCID iD and see what each section can draw on.

    Try it with an ORCID iD · Data and code · DOI

  • OpenResearchMetrics

    Transparent open science indicators for responsible research assessment. Each indicator stands alone, with its evidence and limits; there is no composite score.

    Try it with an ORCID iD · Source code · DOI

Teaching resources and open data

  • IxD Lab

    A learning and experimentation environment for interaction design: fifteen hands-on labs in three modules that run in the browser, with an optional AI tutor. Open educational resource, in English and Spanish.

    Open the labs · Source code

  • SynthVisCom

    A synthetic dataset for visual communication education and research: 2,000 designs with their images, 1,000 fictitious participants and 20,000 simulated responses, with known generating effects.

    Website and explorer · Data and code · DOI

Research projects and infrastructure

  • REPRO2IMPACT

    Research project on reproducibility indicators for measuring the academic and social impact of research. Its open outputs include OpenResearchMetrics, ReproImage and the Narrative CV Crosswalk.

    Project page

  • research-tools-ops

    The shared, automated maintenance that keeps these tools working with minimal human time, while scientific changes always wait for review.

    Source code · DOI
