Appendix C — Verification lab

This appendix complements unit 1 with a timeline of disinformation, a tool for evaluating sources and an activity for spotting red flags.

Timeline: disinformation, science and regulation

  1. 2016Oxford Dictionaries chooses "post-truth" as its word of the year.
  2. 2017IFLA publishes the infographic "How to Spot Fake News", based on a FactCheck.org article.
  3. 2018Vosoughi, Roy and Aral (Science) show that on Twitter falsehood spreads farther and faster than truth. The EU adopts the Code of Practice on Disinformation.
  4. 2020The WHO warns of an "infodemic" during COVID-19.
  5. 2022The EU adopts the Digital Services Act and strengthens the Code of Practice.
  6. 2023AI-generated images go viral as if they were real photographs.
  7. 2024The EU AI Act is adopted, requiring deepfakes to be labelled from August 2026.

Lab: evaluate a source with the CRAAP test

Lab · runs in your browser

The CRAAP test, created at the Meriam Library of California State University, Chico, evaluates a source with five criteria. Score a source you are using (from 0 to 10) and look at its profile.

rangoC = window.Lab.rango
viewof cActualidad = rangoC("Currency: is it recent enough for your topic? Is it updated?", [0, 10], {value: 7})
viewof cRelevancia = rangoC("Relevance: does it answer your question at the right level?", [0, 10], {value: 8})
viewof cAutoridad = rangoC("Authority: who signs it? Do they have credentials and an affiliation?", [0, 10], {value: 4})
viewof cExactitud = rangoC("Accuracy: does it provide evidence and verifiable sources? Has it been reviewed?", [0, 10], {value: 3})
viewof cProposito = rangoC("Purpose: does it inform, sell, persuade or entertain?", [0, 10], {value: 5})
{
  const crit = [["Currency", cActualidad], ["Relevance", cRelevancia], ["Authority", cAutoridad], ["Accuracy", cExactitud], ["Purpose", cProposito]];
  const total = crit.reduce((s, c) => s + c[1], 0);
  const peor = [...crit].sort((a, b) => a[1] - b[1])[0];
  const barras = crit.map(([n, v], i) => `<g transform="translate(0 ${i * 34})"><text x="0" y="20" font-size="14" fill="currentColor">${n}</text><rect x="110" y="6" width="300" height="20" rx="4" fill="var(--bs-secondary-bg)"/><rect x="110" y="6" width="${v * 30}" height="20" rx="4" fill="${v < 5 ? "#b3261e" : "#1c6b3a"}"/><text x="${118 + v * 30}" y="21" font-size="13" fill="currentColor">${v}${v < 5 ? " ⚠" : ""}</text></g>`).join("");
  const veredicto = total >= 40 && peor[1] >= 5 ? "A solid source: you can use it, citing it correctly." : total >= 25 ? `Use it with caution and check it against other sources. Its weak point is ${peor[0].toLowerCase()}.` : "An unreliable source: find a better one before using it.";
  const d = html`<div role="status" aria-live="polite"></div>`;
  d.innerHTML = `<svg viewBox="0 0 460 172" width="100%" style="max-width:520px" role="img" aria-label="CRAAP profile: ${crit.map(([n, v]) => n + " " + v).join(", ")}" font-family="inherit">${barras}</svg><p><strong>Total: ${total} out of 50.</strong> ${veredicto}</p>${peor[0] === "Accuracy" || peor[0] === "Authority" ? '<p class="small">Tip: apply <strong>lateral reading</strong> (open other tabs and search for what others say about the source) before reading on.</p>' : ""}`;
  return d;
}

Criteria below 5 are marked with ⚠. A high score does not replace critical judgement: the test is a guide, not a formula.

Lab: misleading charts

Lab · runs in your browser

The same data can tell different stories depending on how they are drawn. These are a library’s (fictitious) monthly loans. Change the chart’s design decisions and see how much loans appear to grow.

casG = window.Lab.casilla
selG = window.Lab.seleccion
viewof cero = casG("The vertical axis starts at 0", {value: true})
viewof periodo = selG("Period shown", ["The whole year", "Only the last 3 months"], {value: "The whole year"})
{
  const meses = ["Jan", "Feb", "Mar", "Apr", "May", "Jun", "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"];
  const v = [1180, 1215, 1240, 1195, 1160, 980, 640, 610, 1120, 1190, 1205, 1260];
  const ini = periodo.startsWith("Only") ? 9 : 0;
  const m = meses.slice(ini), d = v.slice(ini);
  const ymin = cero ? 0 : Math.min(...d) - 20, ymax = Math.max(...d) + 20;
  const W = 520, H = 240, bw = (W - 60) / d.length;
  const y = (x) => H - 30 - (x - ymin) / (ymax - ymin) * (H - 50);
  let svg = `<svg viewBox="0 0 ${W} ${H}" width="100%" style="max-width:560px" role="img" aria-label="Bar chart of loans from ${m[0]} to ${m[m.length - 1]}; the axis starts at ${Math.round(ymin)}" font-family="inherit">`;
  [ymin, (ymin + ymax) / 2, ymax].forEach((t) => svg += `<line x1="44" x2="${W - 10}" y1="${y(t)}" y2="${y(t)}" stroke="currentColor" stroke-opacity="0.15"/><text x="40" y="${y(t) + 4}" font-size="11" text-anchor="end" fill="currentColor">${Math.round(t)}</text>`);
  d.forEach((x, i) => svg += `<rect x="${50 + i * bw + 3}" y="${y(x)}" width="${bw - 6}" height="${H - 30 - y(x)}" fill="#2a78d6" rx="3"/><text x="${50 + i * bw + bw / 2}" y="${H - 12}" font-size="11" text-anchor="middle" fill="currentColor">${m[i]}</text>`);
  svg += "</svg>";
  const primero = d[0], ultimo = d[d.length - 1];
  const real = (ultimo - primero) / primero * 100;
  const visual = ((H - 30 - y(ultimo)) - (H - 30 - y(primero))) / (H - 30 - y(primero)) * 100;
  const f = (x) => (x > 0 ? "+" : "") + x.toFixed(0) + "%";
  const msgs = [];
  if (!cero) msgs.push("The truncated axis turns a small difference into a huge one: compare the height of the bars with the numbers on the axis.");
  if (ini > 0) msgs.push("Showing only three months hides the summer drop and the context of the year: it is cherry picking.");
  const dd = html`<div role="status" aria-live="polite"></div>`;
  dd.innerHTML = `${svg}<p>From <strong>${m[0]}</strong> to <strong>${m[m.length - 1]}</strong> loans change by <strong>${f(real)}</strong>, but the bar grows by <strong>${f(visual)}</strong>${Math.abs(visual - real) > 10 ? " ⚠" : ""}.</p>${msgs.length ? `<ul>${msgs.map((x) => `<li>${x}</li>`).join("")}</ul>` : "<p>With the axis starting at 0 and the full period, the height of the bars is proportional to the data.</p>"}`;
  return dd;
}

In bar charts the axis must start at 0, because we compare lengths. In line charts the axis can be narrowed if this is clearly indicated, because we compare slopes.
