2. Datos tabulares con pandas

pandas organiza los datos en un DataFrame: una tabla con columnas de distinto tipo, parecida a un data.frame de R. Sus operaciones están vectorizadas: se aplican a columnas enteras sin escribir bucles, lo que es más claro y más rápido. Esa idea viene de la programación con matrices que 1 describen para NumPy, la base sobre la que se construye pandas.

Los datos tienen problemas a propósito (años como " 2021" o "s.f.", DOI en varios formatos, duplicados): los limpiaremos en el capítulo 3.

Ejercicio 2.1 · Comprensión de listas

Cuenta cuántos artículos de la lista tienen al menos 10 citas.

«Al menos 10» es mayor o igual: >=.

citas = [12, 0, 45, 7, 3, 10, 28, 1]
len([c for c in citas if c >= 10])

Cuatro artículos: 12, 45, 10 y 28.

Ejercicio 2.2 · Una función

Completa la función para que devuelva el índice h de una lista de citas: el mayor número h tal que h artículos tienen al menos h citas.

El artículo en la posición p (ordenados de más a menos citados) cuenta si tiene al menos p citas.

def indice_h(citas):
    """Calcula el índice h de una lista de citas."""
    ordenadas = sorted(citas, reverse=True)
    h = 0
    for posicion, c in enumerate(ordenadas, start=1):
        if c >= posicion:
            h = posicion
    return h

indice_h([12, 0, 45, 7, 3, 10, 28, 1])

h = 5: hay cinco artículos con al menos cinco citas (45, 28, 12, 10, 7).

Ejercicio 2.3 · pandas

¿Cuál es la mediana de citas de las publicaciones? Convierte primero la columna a número.

El método de pandas para la mediana se llama igual que en inglés.

citas = pd.to_numeric(pub["citas"], errors="coerce")
citas.median()

Los valores no numéricos («NA», «n/d», vacíos) se convierten en NaN y no cuentan.

Caso práctico resuelto

NotaDe un bucle a pandas

Tarea: calcular la media de citas por año.

Versión con bucle y diccionarios:

suma, n = {}, {}
for fila in registros:
    a = fila["anio"]; suma[a] = suma.get(a, 0) + fila["citas"]; n[a] = n.get(a, 0) + 1
medias = {a: suma[a] / n[a] for a in suma}

Versión con pandas, vectorizada:

medias = pub.groupby("anio")["citas"].mean()

La segunda es más corta, más legible y menos propensa a errores. El bucle sigue siendo útil para entender qué hace groupby o para estructuras que no son tablas (JSON anidado).
