Capítulo 4. Consumir API académicas

NotaObjetivos

  • Consultar API académicas abiertas (OpenAlex, Crossref) con Python y R.

Lectura obligatoria

1. Cómo funciona una API web

Una API (application programming interface) web permite que un programa pida datos a un servidor. La mayoría de las API académicas siguen el estilo REST: cada recurso tiene una URL y se pide con el método HTTP GET; la respuesta suele venir en JSON.

GET https://api.openalex.org/works?filter=publication_year:2024,is_oa:true&search=research%20software&per_page=25
     └──────── base ─────────┘└ ruta ┘└───────────────────── parámetros ───────────────────────────────┘
Código de estado Significa Qué hacer
200 Correcto Procesar la respuesta
400 Petición mal formada Revisar los parámetros
401 / 403 Sin autorización Revisar la clave de API o los permisos
404 No existe Comprobar el identificador
429 Demasiadas peticiones Esperar y reintentar más despacio
500-503 Error del servidor Reintentar más tarde con espera creciente

2. API académicas abiertas

  • OpenAlex (Priem et al., 2022): índice abierto (CC0) de trabajos, autores, fuentes, instituciones y temas, con una API gratuita. Sustituto abierto de las bases de datos comerciales para muchos análisis bibliométricos.
  • Crossref: metadatos de los DOI registrados por las editoriales, incluidas las referencias y las financiaciones cuando se depositan.
  • ORCID, DataCite (DOI de datos y software), Europe PMC, arXiv, Zenodo…

Las condiciones de uso (límites, necesidad de clave o de identificarse con un correo) cambian con el tiempo: lee siempre la documentación vigente de cada API antes de lanzar descargas masivas.

3. Descargar de forma responsable

  • Paginación: las API devuelven los resultados por páginas. OpenAlex permite paginar por número de página o, para conjuntos grandes, con un cursor (cursor=* y después el valor de meta.next_cursor).
  • Límites de uso: respeta el número de peticiones por segundo y por día; añade pausas (time.sleep, Sys.sleep) y reintentos con espera creciente ante un 429.
  • Caché: guarda las respuestas en disco y no repitas peticiones que ya tienes. Además, documenta la fecha de descarga: los datos cambian.
  • Claves de API: en variables de entorno, nunca en el código (capítulo 1).
  • Identifícate: muchas API piden un correo en un parámetro o en la cabecera User-Agent para contactarte si hay problemas.

En Python, con requests:

import os, time, requests

def openalex(params, max_paginas=5):
    """Descarga trabajos de OpenAlex paginando con cursor."""
    url, cursor, todos = "https://api.openalex.org/works", "*", []
    for _ in range(max_paginas):
        r = requests.get(url, params={**params, "cursor": cursor, "per_page": 200},
                         headers={"User-Agent": f"mi-proyecto (mailto:{os.environ['MI_CORREO']})"},
                         timeout=30)
        if r.status_code == 429:
            time.sleep(10); continue
        r.raise_for_status()
        datos = r.json()
        todos += datos["results"]
        cursor = datos["meta"].get("next_cursor")
        if not cursor:
            break
        time.sleep(0.2)
    return todos

En R, con httr2:

library(httr2)
resp <- request("https://api.openalex.org/works") |>
  req_url_query(filter = "publication_year:2024,is_oa:true", search = "research software") |>
  req_user_agent(paste0("mi-proyecto (mailto:", Sys.getenv("MI_CORREO"), ")")) |>
  req_retry(max_tries = 3) |>
  req_perform()
datos <- resp_body_json(resp)

Laboratorio: consulta OpenAlex en directo

Laboratorio · consulta en directo la API pública de OpenAlex desde tu navegador

Construye la consulta y observa la URL, el número de resultados y los primeros trabajos. Necesita conexión a internet.

texto = window.Lab.texto
rango = window.Lab.rango
casilla = window.Lab.casilla
viewof q_busca = texto("Búsqueda (título, resumen y texto)", {value: "research software", submit: "Consultar"})
viewof q_desde = rango("Desde el año", [2000, 2026], {value: 2020})
viewof q_oa = casilla("Solo acceso abierto", {value: true})
{
  const filtros = [`from_publication_date:${q_desde}-01-01`, "type:article"].concat(q_oa ? ["is_oa:true"] : []).join(",");
  const url = `https://api.openalex.org/works?search=${encodeURIComponent(q_busca)}&filter=${filtros}&sort=cited_by_count:desc&per_page=5&select=title,publication_year,cited_by_count,doi`;
  const d = html`<div role="status"><p><strong>URL:</strong> <code style="word-break:break-all">${url}</code></p><p>Consultando…</p></div>`;
  const esc = s => String(s ?? "").replace(/&/g, "&amp;").replace(/</g, "&lt;");
  try {
    const r = await fetch(url);
    const j = await r.json();
    d.lastElementChild.remove();
    d.insertAdjacentHTML("beforeend", `<p>Código de estado <strong>${r.status}</strong> · <strong>${(j.meta?.count ?? 0).toLocaleString("es-ES")}</strong> trabajos encontrados. Los cinco más citados:</p>
      <ol>${(j.results || []).map(w => `<li>${esc(w.title)} (${w.publication_year}) · ${w.cited_by_count} citas${w.doi ? ` · <a href="${esc(w.doi)}">${esc(w.doi.replace("https://doi.org/", ""))}</a>` : ""}</li>`).join("")}</ol>
      <p class="small">Prueba a añadir <code>&amp;group_by=publication_year</code> a la URL en otra pestaña: OpenAlex devuelve recuentos agregados sin descargar los trabajos.</p>`);
  } catch (e) {
    d.lastElementChild.outerHTML = '<p class="lab-medio" style="font-weight:600">No se pudo conectar con OpenAlex (¿sin conexión?). Practica con la muestra guardada en los ejercicios.</p>';
  }
  return d;
}

Ejercicios

Ejercicio 4.1 · Construir la URL (Python)

Usa urllib.parse.urlencode para codificar los parámetros. ¿Cómo queda codificado el espacio de la búsqueda?

Llama a la función que has importado: urlencode(params).

from urllib.parse import urlencode
params = {"search": "open science", "filter": "publication_year:2024", "per_page": 25}
url = "https://api.openalex.org/works?" + urlencode(params)
url

El espacio se codifica como + y los dos puntos como %3A. Nunca construyas las URL concatenando texto a mano.

Ejercicio 4.2 · Procesar la respuesta (Python)

La muestra guardada tiene la misma estructura que una respuesta de OpenAlex. ¿Cuántos trabajos tienen al menos 100 citas?

En las respuestas de OpenAlex, la lista de trabajos está en la clave results; los metadatos de la consulta, en meta.

trabajos = respuesta["results"]
sum(1 for w in trabajos if w["cited_by_count"] >= 100)

Ejercicio 4.3 · Autores por país (R)

Cada trabajo tiene una lista de autorías con sus países. Cuenta cuántos trabajos tienen al menos un autor de España (código ES).

El código ISO de España es ES.

tiene_pais <- function(trabajo, codigo) {
  paises <- unlist(lapply(trabajo$authorships, function(a) a$countries))
  codigo %in% paises
}
sum(sapply(oa$results, tiene_pais, codigo = "ES"))

Con simplifyVector = FALSE, el JSON se lee como listas anidadas, que es lo más seguro cuando la estructura es irregular.

Caso práctico resuelto

NotaDescargar todos los resultados con paginación por cursor

Necesitas todos los artículos de 2024 sobre «research software» en OpenAlex (unos pocos miles). Procedimiento:

  1. Primera petición con cursor=* y per_page=200.
  2. Guardar results y leer meta.next_cursor.
  3. Repetir con el nuevo cursor hasta que sea nulo.
  4. Pausa breve entre peticiones y reintento si aparece un 429.
  5. Guardar cada página en disco (pagina_001.json…) para no repetir la descarga si algo falla.
  6. Anotar la fecha y la consulta exacta.

Comprobación: el número de registros descargados debe coincidir con meta.count de la primera respuesta (salvo cambios durante la descarga).
