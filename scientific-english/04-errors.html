Required reading

Coxhead, A. (2000). A new academic word list. TESOL Quarterly, 34(2), 213-238.

1. False friends

False friends look like Spanish words but mean something different. Some appear constantly in research writing:

English word Actually means For the Spanish meaning, use
actual real current (actual)
actually in fact currently (actualmente)
eventually in the end, finally possibly, occasionally (eventualmente)
sensible reasonable sensitive (sensible)
assist help attend (asistir a)
pretend act as if intend, aim (pretender)
contrast (verb) compare to show differences test, check (contrastar hipótesis)
realise become aware carry out, conduct (realizar)
argument line of reasoning plot (argumento de una película)
formation how something forms training (formación)
thesis doctoral dissertation (or an argued claim) also dissertation; for a master’s, often thesis or dissertation

2. Uncountable nouns

These nouns have no plural and do not take a/an: research, evidence, information, equipment, software, feedback, advice, knowledge, progress, work (in the sense of effort). Data is plural in traditional usage (these data are) but often singular today (this data is); be consistent and follow the journal.

  • ✗ several researches → ✓ several studies / much research
  • ✗ an evidence → ✓ a piece of evidence / some evidence
  • ✗ softwares → ✓ software packages / tools

3. Other frequent errors

Error Example Correct
Articles with general plurals The students often drop out. (meaning students in general) Students often drop out.
Missing subject Is important to note… It is important to note…
“Make” calques make a research, make a question do/conduct research, ask a question
Adjective order and plurals differents methods different methods
Prepositions depend of, consist in, interested on depend on, consist of, interested in
Comma before that We found, that… We found that…
Numbers 1.200 participants, 3,5 % 1,200 participants, 3.5%

4. Academic vocabulary

Coxhead (2000) compiled the Academic Word List (AWL): 570 word families that are frequent across academic disciplines but not in general English (analyse, approach, assess, concept, data, establish, factor, interpret, method, significant…). Together they made up around 10% of the words in her corpus of academic texts. Learning them, with their typical collocations (conduct a study, draw a conclusion, raise a question, address a gap), pays off more than learning rare technical terms.

Lab · runs in your browser; your text does not leave it

viewof borrador = area("Your text", {rows: 6, submit: "Check", value: "Actually, several researches have been realised to contrast this hypothesis. The informations were analysed with differents softwares. Is important to note that the results depend of the sample, which consisted in 1.200 students."})
{
  const reglas = [
    [/\bresearches\b/gi, "«research» is uncountable: use «studies» or «research»"], [/\binformations\b/gi, "«information» is uncountable"], [/\bevidences\b/gi, "«evidence» is uncountable"],
    [/\bsoftwares\b/gi, "«software» is uncountable: «software tools»"], [/\bequipments\b/gi, "«equipment» is uncountable"], [/\badvices\b/gi, "«advice» is uncountable"], [/\bfeedbacks\b/gi, "«feedback» is uncountable"],
    [/\bactually\b/gi, "False friend? «actually» = in fact; «actualmente» = currently"], [/\bactual\b/gi, "False friend? «actual» = real; «actual» (es) = current"], [/\beventually\b/gi, "False friend? «eventually» = in the end"],
    [/\brealis(?:e|ed|ing)\b|\brealiz(?:e|ed|ing)\b/gi, "False friend? «realise» = become aware; use «conduct/carry out»"], [/\bcontrast(?:ed)?\b(?=\s+(?:this|the|our|a)\s+hypothes)/gi, "Use «test the hypothesis»"],
    [/\bmak(?:e|ing|e a|ed)\s+(?:a\s+)?research\b/gi, "Use «do/conduct research»"], [/\bdifferents\b/gi, "Adjectives have no plural: «different»"], [/(?:^|[.!?]\s+)Is\s/g, "Missing subject: «It is…»"],
    [/\bdepend(?:s|ed|ing)? of\b/gi, "«depend on»"], [/\bconsist(?:s|ed|ing)? in\b/gi, "«consist of»"], [/\binterested on\b/gi, "«interested in»"],
    [/\b\d{1,3}\.\d{3}\b/g, "Thousands separator in English is a comma: 1,200"], [/\b\d+,\d+\s?%/g, "Decimal point in English: 3.5%"], [/\bassist(?:ed)? to\b/gi, "«attend»"]];
  const esc = s => s.replace(/&/g, "&amp;").replace(/</g, "&lt;");
  const avisos = []; let m = esc(borrador || "");
  for (const [re, msg] of reglas) { const enc = (borrador || "").match(re); if (enc) { avisos.push([enc[0].trim(), msg]); m = m.replace(re, x => `<mark title="${msg}">${x}</mark>`); } }
  const d = html`<div role="status"></div>`;
  d.innerHTML = `<p style="line-height:1.9">${m}</p>${avisos.length ? `<ul>${avisos.map(([w, msg]) => `<li><strong>${esc(w)}</strong>: ${msg}</li>`).join("")}</ul>` : '<p class="lab-bien" style="font-weight:600">No common errors detected. (The lab checks only a list of frequent errors.)</p>'}`;
  return d;
}

Worked example

NoteCorrecting a paragraph by a Spanish speaker

Original: “Actually, the researches about this topic are scarce. In this work we have realised an study with 1.250 students, which consisted in a survey. The informations obtained depend of the faculty.”

Corrected: “Research on this topic is currently scarce. In this study, we conducted a survey of 1,250 students. The information obtained depends on the faculty.”

Errors fixed: actually (false friend) → currently; researches (uncountable) → research; realised (false friend) → conducted; an study → a study; 1.250 → 1,250; consisted in → (restructured); informations → information; depend of → depends on.

Graded exercises

Basic. Correct: “The equipments were sensible to the temperature.”

“The equipment was sensitive to temperature.” (equipment is uncountable; sensible → sensitive).

Advanced. Build your personal list of ten frequent errors from your own texts, with the correction and an example sentence for each.

Classify them (false friends, uncountables, prepositions, articles, punctuation) and review the list before submitting any text in English.
