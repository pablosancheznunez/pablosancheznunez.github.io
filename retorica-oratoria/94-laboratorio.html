Apéndice B — Laboratorio interactivo

Este apéndice reúne un laboratorio y un escenario ramificado para practicar en tu navegador.

Laboratorio: títulos que afirman

Laboratorio · se ejecuta en tu navegador

En el enfoque afirmación-evidencia (Alley), cada diapositiva tiene como título una frase completa que dice la conclusión, y el cuerpo muestra la evidencia visual. Escribe un título y el laboratorio lo revisa.

textoR = window.Lab.texto
viewof tituloDiapo = textoR("Título de tu diapositiva", {value: "Resultados"})
{
  const t = tituloDiapo.trim(), palabras = t.split(/\s+/).filter(Boolean), n = palabras.length;
  const generico = /^(introducción|resultados|metodología|método|métodos|conclusiones?|discusión|objetivos?|contexto|antecedentes|datos|análisis|agradecimientos)$/i.test(t.replace(/[.:]$/, ""));
  const verbo = palabras.some((w) => { const x = w.toLowerCase().replace(/[^a-záéíóúüñ]/g, ""); return ["es", "son", "fue", "fueron", "hay", "está", "están", "puede", "pueden", "reduce", "reducen", "aumenta", "aumentan", "mejora", "mejoran", "duplica", "triplica", "multiplica", "explica", "predice", "muestra", "muestran", "demuestra", "permite", "indica", "sugiere", "supera", "crece", "cae", "disminuye", "depende", "cambia", "funciona", "falla", "afecta", "baja", "sube", "tarda", "cuesta", "necesita", "requiere", "evita", "acelera", "frena", "mantiene", "genera"].includes(x) || (x.length > 4 && /(aron|ieron|aban|ían|ará|erá|irá|arán|erán|irán)$/.test(x)); });
  const cifra = /\d/.test(t);
  const checks = [
    [!generico, "No es una etiqueta genérica («Resultados», «Metodología»…)."],
    [n >= 6, "Tiene al menos 6 palabras: es una frase, no un tema."],
    [n <= 20, "No pasa de 20 palabras (cabe en dos líneas)."],
    [verbo, "Contiene un verbo que afirma algo."],
    [cifra, "Incluye una cifra o un dato concreto (recomendable, no obligatorio)."]];
  const nota = checks.slice(0, 4).filter((c) => c[0]).length;
  const d = html`<div role="status" aria-live="polite"></div>`;
  d.innerHTML = `<div class="p-3 border rounded mb-2" style="aspect-ratio:16/9;max-width:480px;display:flex;flex-direction:column"><div style="font-size:1.25rem;font-weight:600;line-height:1.25">${t.replace(/[&<>]/g, "") || "(sin título)"}</div><div class="mt-auto small text-body-secondary">[evidencia visual: gráfico, imagen o esquema]</div></div>
  <ul class="list-unstyled">${checks.map(([ok, txt], i) => `<li>${ok ? "✓" : i === 4 ? "○" : "✗"} ${txt}</li>`).join("")}</ul>
  <p>${nota === 4 ? "Buen título-afirmación: el público sabe qué debe recordar aunque no lea nada más." : "Prueba a reescribirlo como la conclusión de la diapositiva. Por ejemplo: «La tutoría entre iguales reduce el abandono del 18 % al 9 %»."}</p>`;
  return d;
}
