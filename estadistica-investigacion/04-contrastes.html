1. La lógica del contraste

  1. Se plantea una hipótesis nula (H₀), normalmente «no hay efecto» o «no hay diferencia».
  2. Se calcula un estadístico que mide cuánto se alejan los datos de lo que predice H₀.
  3. El valor p es la probabilidad de obtener un estadístico tan extremo o más que el observado si H₀ y todos los supuestos del modelo fueran ciertos.
  4. Si p es menor que un umbral α fijado de antemano (por convención, 0,05), se rechaza H₀.

Este procedimiento controla a largo plazo dos errores: el de tipo I (rechazar H₀ cuando es cierta, con probabilidad α) y el de tipo II (no rechazarla cuando es falsa, con probabilidad β; la potencia es 1 − β, capítulo 5).

2. Seis principios de la ASA

En 2016, la American Statistical Association publicó por primera vez una declaración sobre un procedimiento concreto (Wasserstein y Lazar, 2016):

  1. Los valores p pueden indicar cuán incompatibles son los datos con un modelo estadístico concreto.
  2. No miden la probabilidad de que la hipótesis sea cierta, ni la de que los datos se deban solo al azar.
  3. Las conclusiones científicas y las decisiones no deberían basarse solo en si p supera un umbral.
  4. Una inferencia correcta exige informar de todo con transparencia.
  5. Un valor p no mide el tamaño del efecto ni la importancia del resultado.
  6. Por sí solo, un valor p no es una buena medida de la evidencia sobre un modelo o una hipótesis.

3. Laboratorio: ¿cómo se distribuyen los valores p?

Laboratorio · simulación en tu navegador

Simulamos 2000 estudios con dos grupos. Si no hay efecto, los valores p se reparten de manera uniforme entre 0 y 1: un 5 % cae por debajo de 0,05 por puro azar. Si hay efecto, se amontonan cerca de 0, tanto más cuanto mayor es la potencia.

rango = window.Lab.rango
viewof p_d = rango("Tamaño del efecto real (d de Cohen)", [0, 1], {step: 0.05, value: 0, formato: x => x.toFixed(2).replace(".", ",")})
viewof p_n = rango("Personas por grupo", [5, 100], {step: 5, value: 20})
{
  let s = 3; const u = () => (s = (s * 16807) % 2147483647) / 2147483647;
  const nrm = () => Math.sqrt(-2 * Math.log(u())) * Math.cos(2 * Math.PI * u());
  const Phi = z => { const t = 1 / (1 + 0.2316419 * Math.abs(z)), d = 0.3989423 * Math.exp(-z * z / 2);
    const p = d * t * (0.3193815 + t * (-0.3565638 + t * (1.781478 + t * (-1.821256 + t * 1.330274)))); return z > 0 ? 1 - p : p; };
  const ps = Array.from({length: 2000}, () => { let a = 0, b = 0; for (let i = 0; i < p_n; i++) { a += nrm(); b += nrm() + p_d; }
    const z = (b / p_n - a / p_n) / Math.sqrt(2 / p_n); return 2 * (1 - Phi(Math.abs(z))); });
  const bins = Array(20).fill(0); ps.forEach(p => bins[Math.min(19, Math.floor(p * 20))]++);
  const max = Math.max(...bins), sig = ps.filter(p => p < 0.05).length / 2000;
  const barras = bins.map((v, i) => `<rect x="${30 + i * 22}" y="${180 - 160 * v / max}" width="20" height="${160 * v / max}" fill="${i === 0 ? "#eb6834" : "#2a78d6"}"/>`).join("");
  const d = html`<div role="status"></div>`;
  d.innerHTML = `<p><strong>${(100 * sig).toFixed(1).replace(".", ",")} %</strong> de los estudios obtiene <em>p</em> &lt; 0,05 ${p_d === 0 ? "(todos son falsos positivos)" : "(es la potencia, aproximadamente)"}.</p>
   <svg viewBox="0 0 480 205" width="100%" style="max-width:480px" role="img" aria-label="Histograma de 2000 valores p entre 0 y 1">${barras}
   <line x1="30" x2="470" y1="180" y2="180" stroke="currentColor" stroke-opacity=".4"/>
   <text x="30" y="198" font-size="10" fill="currentColor">0</text><text x="250" y="198" font-size="10" text-anchor="middle" fill="currentColor">0,5</text><text x="470" y="198" font-size="10" text-anchor="end" fill="currentColor">1</text></svg>
   <p class="small">En naranja, la barra de <em>p</em> &lt; 0,05. Prueba d = 0,5 con 20 por grupo y después con 80: el mismo efecto, valores <em>p</em> muy distintos de un estudio a otro.</p>`;
  return d;
}

4. Contrastes básicos en R

Pregunta Datos Contraste En R
¿Difieren dos medias? Dos grupos independientes t de Welch t.test(y ~ grupo)
¿Cambia una medida antes y después? Medidas emparejadas t emparejada t.test(antes, despues, paired = TRUE)
¿Difieren dos distribuciones sin suponer normalidad? Dos grupos Wilcoxon-Mann-Whitney wilcox.test(y ~ grupo)
¿Difieren varias medias? Tres o más grupos ANOVA aov(y ~ grupo)
¿Están asociadas dos variables categóricas? Tabla de frecuencias Ji cuadrado chisq.test(tabla)
¿Hay relación lineal? Dos cuantitativas Correlación cor.test(x, y)

La salida da el estadístico t, los grados de libertad, el valor p, el intervalo de confianza de la diferencia y las medias. Lee primero el intervalo: la tutoría podría mejorar la nota en casi un punto o empeorarla ligeramente; los datos son compatibles con un efecto nulo, pero también con uno moderado. «No significativo» no es «no hay efecto».

5. Muchas pruebas, muchos falsos positivos

Con 20 contrastes independientes y α = 0,05, la probabilidad de al menos un falso positivo es 1 − 0,95²⁰ ≈ 64 %. Las correcciones (Bonferroni, Holm, tasa de falsos descubrimientos) ajustan los valores p cuando se hacen muchas pruebas:

Ejercicio 4.1

¿Está asociada la ansiedad con la nota? Calcula cor.test() y extrae el valor p.

El elemento con el valor p se llama p.value.

cor.test(d$ansiedad, d$nota)$p.value

Mira también $conf.int: el intervalo de la correlación dice más que el valor p.

Ejercicio 4.2

Calcula la probabilidad de al menos un falso positivo al hacer 10 contrastes independientes con α = 0,05.

El exponente es el número de contrastes.

1 - (1 - 0.05)^10

Alrededor del 40 %.

Caso práctico resuelto

NotaLeer bien un valor p

Un estudio informa: diferencia de 3 puntos en la nota entre quienes hicieron un taller y quienes no; t(118) = 2,1; p = 0,038.

Lo que significa: si no hubiera ninguna diferencia en la población, sería poco frecuente (en torno al 4 % de las veces) observar una diferencia como esta o mayor.

Lo que no significa:

  • No es la probabilidad de que la hipótesis nula sea cierta.
  • No dice que el efecto sea grande o importante: hay que mirar el tamaño del efecto y su intervalo.
  • p = 0,038 y p = 0,052 no son resultados opuestos: la evidencia es muy parecida.

Informe completo: diferencia de 3 puntos, IC 95 % [0,2; 5,8], d de Cohen ≈ 0,38, p = 0,038.

Ejercicios graduados

Básico. Un estudio obtiene p = 0,30. ¿Demuestra que no hay efecto?

No: un resultado no significativo no demuestra la ausencia de efecto. Puede deberse a poca potencia; hay que mirar el intervalo de confianza para ver qué efectos son compatibles con los datos.

Avanzado. Busca en un artículo de tu campo un resultado con valor p y reescribe su descripción con tamaño del efecto e intervalo de confianza.

La reescritura debe sustituir «significativo» por la magnitud del efecto con su incertidumbre y valorar su relevancia práctica.
