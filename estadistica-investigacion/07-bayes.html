1. Probabilidad como grado de creencia

En la estadística frecuentista, la probabilidad describe frecuencias a largo plazo y los parámetros son fijos. En la bayesiana, la probabilidad expresa incertidumbre sobre los parámetros, y se actualiza con los datos mediante el teorema de Bayes:

posterior ∝ verosimilitud × previa

  • La distribución previa recoge lo que se sabía (o se supone) antes de los datos.
  • La verosimilitud dice qué valores del parámetro hacen más probables los datos observados.
  • La distribución posterior combina ambas: es lo que se sabe después.

Su gran ventaja es responder directamente a la pregunta que solemos querer: ¿qué valores del parámetro son creíbles dados los datos? Su gran exigencia es explicitar y justificar la previa.

2. Un caso que se calcula a mano: una proporción

Queremos estimar la proporción de doctorandos que aprueban un examen. Con una previa Beta(a, b) y k aprobados de n, la posterior es Beta(a + k, b + n − k). La previa Beta(1, 1) es plana: todos los valores entre 0 y 1 igual de creíbles.

El intervalo de credibilidad del 95 % sí admite la lectura intuitiva: dada la previa y los datos, hay un 95 % de probabilidad de que la proporción esté entre esos valores.

Laboratorio: actualizar con los datos

Laboratorio · cálculo en tu navegador

Elige una previa (su media y cuánta información aporta, en «observaciones equivalentes») y unos datos. Mira cómo la posterior se desplaza desde la previa hacia los datos y cómo los datos dominan cuando son abundantes.

rango = window.Lab.rango
viewof b_media = rango("Media de la previa", [0.05, 0.95], {step: 0.05, value: 0.5, formato: x => x.toFixed(2).replace(".", ",")})
viewof b_peso = rango("Peso de la previa (observaciones equivalentes)", [2, 200], {step: 2, value: 2})
viewof b_n = rango("Observaciones (n)", [0, 200], {step: 1, value: 20})
viewof b_k = rango("Éxitos observados", [0, 200], {step: 1, value: 15})
{
  const n = b_n, k = Math.min(b_k, b_n), a = b_media * b_peso, b = (1 - b_media) * b_peso;
  const lgamma = z => { const c = [76.18009172947146, -86.50532032941677, 24.01409824083091, -1.231739572450155, 0.1208650973866179e-2, -0.5395239384953e-5];
    let x = z, y = z, t = x + 5.5; t -= (x + 0.5) * Math.log(t); let s = 1.000000000190015; for (const ci of c) s += ci / ++y; return -t + Math.log(2.5066282746310005 * s / x); };
  const dbeta = (x, p, q) => x <= 0 || x >= 1 ? 0 : Math.exp((p - 1) * Math.log(x) + (q - 1) * Math.log(1 - x) - (lgamma(p) + lgamma(q) - lgamma(p + q)));
  const xs = Array.from({length: 199}, (_, i) => (i + 1) / 200);
  const prev = xs.map(x => dbeta(x, a, b)), post = xs.map(x => dbeta(x, a + k, b + n - k)), ver = xs.map(x => n ? Math.exp(k * Math.log(x) + (n - k) * Math.log(1 - x)) : 1);
  const norm = v => { const m = Math.max(...v.filter(Number.isFinite)); return v.map(y => y / m); };
  const X = x => 20 + x * 440, Y = y => 170 - y * 150;
  const linea = (v, c, ds) => `<polyline points="${norm(v).map((y, i) => `${X(xs[i])},${Y(y)}`).join(" ")}" fill="none" stroke="${c}" stroke-width="2.2" ${ds ? `stroke-dasharray="${ds}"` : ""}/>`;
  const pa = a + k, pb = b + n - k, media = pa / (pa + pb);
  const cdf = []; let acc = 0; post.forEach(p => { acc += p; cdf.push(acc); }); const tot = acc;
  const q = p => xs[cdf.findIndex(c => c / tot >= p)];
  const f = v => v.toFixed(2).replace(".", ",");
  const d = html`<div role="status"></div>`;
  d.innerHTML = `<p>Posterior: Beta(${f(pa)}; ${f(pb)}) · media <strong>${f(media)}</strong> · intervalo de credibilidad del 95 % ≈ [${f(q(.025))}; ${f(q(.975))}]</p>
   <svg viewBox="0 0 480 190" width="100%" style="max-width:480px" role="img" aria-label="Curvas de la previa, la verosimilitud y la posterior">
   <line x1="20" x2="460" y1="170" y2="170" stroke="currentColor" stroke-opacity=".4"/>
   ${linea(prev, "#8a8984", "5 4")}${n ? linea(ver, "#1baf7a", "2 3") : ""}${linea(post, "#2a78d6")}
   <text x="20" y="186" font-size="10" fill="currentColor">0</text><text x="460" y="186" font-size="10" text-anchor="end" fill="currentColor">1</text></svg>
   <p class="small">Gris discontinua: previa · verde punteada: verosimilitud (los datos) · azul: posterior. Curvas reescaladas a la misma altura. ${b_k > b_n ? "Hay más éxitos que observaciones: se usa k = n." : ""}</p>`;
  return d;
}

3. Contrastar hipótesis: el factor de Bayes

El factor de Bayes (BF₁₀) compara cuánto mejor predicen los datos una hipótesis (H₁) que otra (H₀). Un BF₁₀ = 6 significa que los datos son seis veces más probables bajo H₁ que bajo H₀. A diferencia del valor p, puede aportar evidencia a favor de la hipótesis nula. Depende, eso sí, de cómo se defina la previa de H₁.

4. ¿Cuándo usar el enfoque bayesiano?

  • Cuando hay información previa legítima que conviene incorporar.
  • Con muestras pequeñas o modelos complejos (multinivel), donde las previas estabilizan las estimaciones.
  • Cuando se quiere cuantificar la evidencia a favor de la nula.
  • Cuando se quiere hablar en términos de probabilidad de los parámetros.

En R, paquetes como brms o rstanarm ajustan modelos bayesianos con una sintaxis parecida a lm(), y BayesFactor calcula factores de Bayes. Fuera del navegador, son el siguiente paso natural tras este capítulo.

Ejercicio 7.1

Con una previa Beta(1, 1) y 15 aprobados de 20, calcula la media de la posterior: (a + k) / (a + b + n).

El denominador suma a, b y el número de observaciones n.

a <- 1; b <- 1; k <- 15; n <- 20
(a + k) / (a + b + n)

0,727: un poco por debajo de la proporción observada (0,75), atraída hacia la media de la previa (0,5).

Ejercicio 7.2

Calcula el intervalo de credibilidad del 95 % de esa posterior, Beta(16, 6).

El límite superior es el cuantil 0,975.

qbeta(c(0.025, 0.975), 16, 6)

Caso práctico resuelto

NotaActualizar una creencia con datos

Quieres estimar la proporción de doctorandos que publican durante el primer año. A priori, por estudios previos, crees que ronda el 20 % (distribución Beta(2, 8)). Observas 15 que publican de 40.

  • Posterior: Beta(2 + 15, 8 + 25) = Beta(17, 33).
  • Media posterior: 17 / 50 = 0,34. Los datos (15/40 = 0,375) acercan la estimación hacia ellos, moderados por la información previa.
  • Intervalo de credibilidad del 95 %: aproximadamente [0,22; 0,47]; aquí sí puede decirse que hay un 95 % de probabilidad (según el modelo) de que la proporción esté en ese intervalo.

Con más datos, la información previa pesa cada vez menos.

Ejercicios graduados

Básico. Con una previa Beta(1, 1) y 15 éxitos en 20 intentos, ¿cuál es la media posterior?

(1 + 15) / (1 + 1 + 20) = 16 / 22 ≈ 0,73.

Avanzado. Compara la posterior con tres previas distintas (poco informativa, optimista y pesimista) para los mismos datos y comenta la sensibilidad del resultado.

Con pocos datos, la previa influye bastante; con muchos, las tres posteriores convergen. Informar del análisis de sensibilidad es una buena práctica.
