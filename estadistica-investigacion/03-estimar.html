Lectura obligatoria

Cumming, G. (2014). The new statistics: Why and how. Psychological Science, 25(1), 7-29.

1. Una muestra es una de muchas posibles

Si repitieras el estudio con otros 120 doctorandos, la media sería otra. La distribución muestral describe cómo varía un estadístico (la media, una diferencia, una pendiente) de muestra en muestra. Su desviación típica es el error típico: para una media, aproximadamente sd / sqrt(n). Cuanto mayor es la muestra, más precisa es la estimación, pero la precisión crece con la raíz de n: para reducir el error a la mitad hace falta cuadruplicar la muestra.

2. El intervalo de confianza

Un intervalo de confianza del 95 % es un procedimiento que, si se repitiera el estudio muchas veces, contendría el valor verdadero en el 95 % de las repeticiones. Para un estudio concreto, una forma práctica de leerlo (Cumming, 2014) es: el intervalo reúne los valores del parámetro razonablemente compatibles con los datos, y los valores del centro son más plausibles que los de los extremos.

AdvertenciaInterpretaciones erróneas frecuentes
  • «Hay un 95 % de probabilidad de que el valor verdadero esté en este intervalo». En la estadística frecuentista, el valor verdadero es fijo: o está o no está; el 95 % se refiere al procedimiento.
  • «El 95 % de los datos está dentro del intervalo». El intervalo es para el parámetro (la media), no para las observaciones individuales.
  • «Si dos intervalos se solapan, no hay diferencia». Pueden solaparse algo y la diferencia ser significativa: hay que calcular el intervalo de la diferencia.

Laboratorio: el baile de los intervalos

Laboratorio · simulación en tu navegador

Simulamos 50 estudios de la misma población (media verdadera = 50, desviación típica = 10). Cada línea es el intervalo de confianza de un estudio; en naranja, los que no contienen el valor verdadero. Cambia el tamaño de la muestra y el nivel de confianza, y pulsa Repetir.

  const ics = Array.from({length: 50}, () => { const x = Array.from({length: b_n}, () => 50 + 10 * nrm());

  const d = html`<div role="status"></div>`;
  d.innerHTML = `<p>${50 - fuera} de 50 intervalos contienen la media verdadera (${fuera} no, en naranja). Lo esperado: ${Math.round(50 * +b_conf)}.</p>
   <svg viewBox="0 0 480 320" width="100%" style="max-width:480px" role="img" aria-label="50 intervalos de confianza; ${fuera} no contienen el valor verdadero">

3. Remuestreo: el bootstrap

Cuando no hay una fórmula sencilla (por ejemplo, para una mediana), el bootstrap aproxima la distribución muestral remuestreando con reemplazo los propios datos muchas veces.

Ejercicio 3.1

Calcula el error típico de la nota media: la desviación típica entre la raíz del tamaño de la muestra.

La raíz cuadrada en R es sqrt().

sd(d$nota) / sqrt(nrow(d))

Unos 0,14 puntos. El IC 95 % es, aproximadamente, la media ± 2 errores típicos.

Ejercicio 3.2

Calcula el intervalo de confianza del 99 % de la nota media.

El 99 % se escribe 0.99.

t.test(d$nota, conf.level = 0.99)$conf.int

Más ancho que el del 95 %: más confianza exige un intervalo mayor.

Caso práctico resuelto

NotaInterpretar un intervalo de confianza

En una muestra de 120 doctorandos, la media de horas de sueño es 6,8 con un intervalo de confianza del 95 % de [6,6; 7,0].

  • Interpretación correcta: el procedimiento que genera estos intervalos captura el valor poblacional en el 95 % de las muestras; los valores entre 6,6 y 7,0 son compatibles con los datos.
  • Interpretación incorrecta: «hay un 95 % de probabilidad de que la media verdadera esté entre 6,6 y 7,0» (en el enfoque frecuentista, el parámetro es fijo; la probabilidad se refiere al procedimiento).
  • Precisión: un intervalo estrecho indica una estimación precisa; para reducirlo a la mitad hace falta aproximadamente cuadruplicar la muestra.

Ejercicios graduados

Básico. Si con n = 100 el margen de error es ±0,4, ¿qué margen aproximado tendrás con n = 400?

Aproximadamente ±0,2: el error típico depende de 1/√n, y √400 = 2 × √100.

Avanzado. Simula en R 100 intervalos de confianza de muestras de una población conocida y cuenta cuántos contienen el valor verdadero.

Deberían ser alrededor de 95. Este ejercicio muestra que la confianza es una propiedad del procedimiento, no de un intervalo concreto.
