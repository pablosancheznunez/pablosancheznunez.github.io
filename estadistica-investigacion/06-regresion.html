Capítulo 6. Regresión

NotaObjetivos
  • Ajustar e interpretar modelos de regresión lineal simple y múltiple.
  • Comprobar los supuestos con los residuos.
  • Saber qué puede y qué no puede decir un coeficiente sobre causas.

Lectura obligatoria

Schielzeth, H. (2010). Simple means to improve the interpretability of regression coefficients. Methods in Ecology and Evolution, 1(2), 103-113.

1. La recta que mejor se ajusta

La regresión lineal modela una variable resultado como una combinación lineal de predictores más un error:

nota = b0 + b1 · horas + error

b1 es el cambio esperado en la nota por cada hora más de estudio; b0, la nota esperada con 0 horas (a menudo, sin sentido práctico: por eso conviene centrar los predictores, como recomienda Schielzeth, 2010).

Cada hora más de estudio se asocia con unos 0,14 puntos más de nota (IC 95 %: 0,09 a 0,19). El R² indica qué proporción de la variabilidad de la nota explica el modelo (aquí, en torno al 22 %).

2. Varios predictores a la vez

En la regresión múltiple, cada coeficiente es la asociación con el resultado manteniendo constantes los demás predictores del modelo.

Con los predictores centrados, la constante es la nota esperada en el grupo de referencia (control) para alguien con horas, sueño y ansiedad medios. Fíjate en que el coeficiente de grupotutoria (el efecto de la tutoría ajustado por las demás variables) se estima con algo más de precisión que en la simple comparación de medias: ajustar por covariables que predicen el resultado aumenta la precisión en un experimento.

3. Comprobar los supuestos

La regresión lineal supone, sobre todo: relación lineal, independencia de los errores, varianza constante y, para los intervalos con muestras pequeñas, errores aproximadamente normales. Se comprueba mirando los residuos:

Buscas que los residuos no formen patrones (curvas, embudos) y que los puntos del gráfico Q-Q sigan la recta.

Laboratorio: un punto puede cambiarlo todo

Laboratorio · se ejecuta en tu navegador

Diez puntos sin relación aparente y un undécimo que puedes mover. Un punto alejado en el eje x (con mucha palanca) puede crear o destruir una pendiente.

rango = window.Lab.rango
viewof q_x = rango("Posición x del punto móvil", [0, 20], {step: 0.5, value: 5})
viewof q_y = rango("Posición y del punto móvil", [0, 20], {step: 0.5, value: 5})
{
  const base = [[2, 5], [3, 7], [4, 4], [5, 6], [5.5, 5], [6, 7.5], [6.5, 4.5], [7, 6], [8, 5], [9, 6.5]];
  const pts = base.concat([[q_x, q_y]]);
  const n = pts.length, mx = pts.reduce((s, p) => s + p[0], 0) / n, my = pts.reduce((s, p) => s + p[1], 0) / n;
  const sxy = pts.reduce((s, p) => s + (p[0] - mx) * (p[1] - my), 0), sxx = pts.reduce((s, p) => s + (p[0] - mx) ** 2, 0), syy = pts.reduce((s, p) => s + (p[1] - my) ** 2, 0);
  const b = sxy / sxx, a = my - b * mx, r = sxy / Math.sqrt(sxx * syy);
  const X = x => 30 + x * 22, Y = y => 220 - y * 10;
  const f = v => v.toFixed(2).replace(".", ",");
  const d = html`<div role="status"></div>`;
  d.innerHTML = `<p>Pendiente = <strong>${f(b)}</strong> · <em>r</em> = ${f(r)}</p>
   <svg viewBox="0 0 480 240" width="100%" style="max-width:480px" role="img" aria-label="Diagrama de dispersión con once puntos y su recta; pendiente ${f(b)}">
   <line x1="30" y1="220" x2="470" y2="220" stroke="currentColor" stroke-opacity=".4"/><line x1="30" y1="10" x2="30" y2="220" stroke="currentColor" stroke-opacity=".4"/>
   <line x1="${X(0)}" y1="${Y(a)}" x2="${X(20)}" y2="${Y(a + b * 20)}" stroke="#2a78d6" stroke-width="2"/>
   ${base.map(p => `<circle cx="${X(p[0])}" cy="${Y(p[1])}" r="5" fill="#2a78d6"/>`).join("")}
   <circle cx="${X(q_x)}" cy="${Y(q_y)}" r="7" fill="#eb6834"/></svg>
   <p class="small">Lleva el punto naranja a x = 20, y = 20: aparece una relación «fuerte» creada por un solo dato. Revisa siempre los puntos influyentes (en R, <code>cooks.distance()</code>).</p>`;
  return d;
}

Ejercicio 6.1

Usa el modelo m1 para predecir la nota de alguien que estudia 20 horas a la semana.

Sustituye el hueco por 20.

predict(m1, newdata = data.frame(horas = 20))

Unos 7,2 puntos. Con interval = "prediction" verás el intervalo para una persona concreta, mucho más ancho que el de la media.

Ejercicio 6.2

Calcula el R² del modelo con horas y sueño.

La variable del sueño se llama sueno.

m <- lm(nota ~ horas + sueno, data = d)
summary(m)$r.squared

Algo mayor que con solo las horas. El R² siempre sube al añadir predictores, aunque no aporten nada: por eso existe el R² ajustado.

Caso práctico resuelto

NotaInterpretar los coeficientes de una regresión

Modelo: nota ~ horas + sueno con los datos del libro. Supongamos que el resultado es: intersección 4,1; horas 0,05; sueño 0,30.

  • horas = 0,05: por cada hora semanal más de estudio, la nota aumenta en promedio 0,05 puntos, manteniendo constante el sueño.
  • sueno = 0,30: cada hora más de sueño se asocia con 0,3 puntos más, a igualdad de horas de estudio.
  • Intersección: nota prevista con 0 horas de estudio y 0 de sueño: no tiene sentido sustantivo; centrar las variables la hace interpretable (nota prevista para valores medios).
  • R² indica la proporción de la variación explicada, no si el modelo es causal ni si está bien especificado: hay que revisar los residuos.

Ejercicios graduados

Básico. ¿Qué significa un coeficiente de 0,30 para «sueño» en la regresión anterior?

Que, a igualdad de horas de estudio, cada hora adicional de sueño se asocia con 0,3 puntos más de nota media en la muestra. No implica causalidad.

Avanzado. Ajusta el modelo con las variables centradas e interpreta de nuevo la intersección.

Con scale(x, scale = FALSE) o restando la media, la intersección pasa a ser la nota prevista para un doctorando con horas y sueño medios; los demás coeficientes no cambian.
