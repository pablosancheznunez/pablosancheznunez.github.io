Apéndice A — Laboratorio de diseño visual

Este apéndice reúne herramientas interactivas para practicar las decisiones de alta fidelidad sobre el ejemplo de ReservaSala: comparar versiones, ajustar una escala tipográfica y una de espaciado, ver los estados reales de un componente y probar una microinteracción accesible. Todo funciona en tu navegador.

Antes y después

Esta actividad necesita JavaScript.

rango = window.Lab.rango
seleccion = window.Lab.seleccion
casilla = window.Lab.casilla
viewof base = rango("Tamaño base (px)", [14, 20], {step: 1, value: 16})
viewof razon = seleccion("Razón de la escala", ["1,125 · segunda mayor", "1,2 · tercera menor", "1,25 · tercera mayor", "1,333 · cuarta justa", "1,5 · quinta justa"], {value: "1,25 · tercera mayor"})
{
  const k = parseFloat(razon.replace(",", "."));
  const niveles = [["Título de pantalla", 3, 600, "Sala 2.14"], ["Encabezado", 2, 600, "Disponibilidad hoy"], ["Subtítulo", 1, 600, "Biblioteca de Getafe"], ["Texto", 0, 400, "Máximo 2 horas al día. Confirma tu llegada en 15 minutos."], ["Pequeño", -1, 400, "Actualizado hace 2 minutos"]];
  const px = n => Math.round(base * Math.pow(k, n));
  const d = html`<div role="status"></div>`;
  d.innerHTML = `<div class="p-3 border rounded">${niveles.map(([n, e, w, s]) => `<div style="font-size:${px(e)}px;font-weight:${w};line-height:${e > 0 ? 1.25 : 1.5};margin:.25rem 0">${s}</div>`).join("")}</div>
   <table class="table table-sm mt-2"><thead><tr><th scope="col">Nivel</th><th scope="col">Tamaño</th><th scope="col">Token</th></tr></thead><tbody>${niveles.map(([n, e]) => `<tr><td>${n}</td><td>${px(e)} px</td><td><code>--fuente-${e >= 0 ? "n" + e : "menos1"}: ${px(e)}px;</code></td></tr>`).join("")}</tbody></table>
   <p class="small">${k >= 1.333 ? "Razón amplia: mucho contraste entre niveles; vigila que los títulos no ocupen demasiado en móvil." : k <= 1.125 ? "Razón estrecha: pocos contrastes; la jerarquía tendrá que apoyarse en el peso y el espacio." : "Razón equilibrada, habitual en interfaces."}</p>`;
  return d;
}
viewof unidad = seleccion("Unidad base", ["4 px", "8 px"], {value: "8 px"})
viewof densidad = rango("Densidad (multiplicador)", [1, 3], {step: 1, value: 2})
{
  const u = parseInt(unidad), m = densidad;
  const esc = [1, 2, 3, 4, 6, 8].map(x => x * u);
  const d = html`<div role="status"></div>`;
  d.innerHTML = `<p>Escala: ${esc.map(x => `<code>${x}</code>`).join(" · ")} px</p>
   <div style="max-width:320px;border:1px solid var(--bs-border-color);border-radius:12px;padding:${u * m}px">
     <div style="font-weight:600;font-size:18px;margin-bottom:${u * m / 2}px">Sala 2.14</div>
     <div style="color:var(--bs-secondary-color);margin-bottom:${u * m}px">6 personas · planta 2</div>

  return d;

Pasa el ratón, pulsa y navega con el tabulador sobre estos botones reales: cada estado tiene su especificación.

Estado Especificación
Normal Fondo #1c6b3a, texto blanco (contraste ≈ 6,9:1)
Hover Fondo un 10 % más oscuro
Pulsado Desplazamiento de 1 px y fondo más oscuro
Foco Contorno azul de 3 px separado 3 px: visible con teclado
Cargando Indicador giratorio y aria-busy="true"; sin animación si el usuario pide reducir el movimiento
Desactivado Gris con texto oscuro; evita desactivar sin explicar por qué 

viewof reducir = casilla("Simular «reducir movimiento» del sistema", {value: false})
{
  const c = html`<div><button type="button" class="btn btn-primary">Reservar</button> <span class="ms-2" aria-live="polite"></span>
    <div style="height:10px;max-width:320px;background:var(--bs-secondary-bg);border-radius:5px;margin-top:12px;overflow:hidden"><div style="height:100%;width:0;background:#1c6b3a"></div></div></div>`;
  const [b, msg, barra] = [c.querySelector("button"), c.querySelector("span"), c.querySelector("div > div > div")];
  b.onclick = () => {
    msg.textContent = "Reservando…";
    barra.style.transition = reducir ? "none" : "width 1.2s ease-out";
    barra.style.width = "0"; void barra.offsetWidth; barra.style.width = "100%";
    setTimeout(() => { msg.textContent = "✓ Sala reservada"; }, reducir ? 50 : 1200);
  };
  return c;
}

La animación dura lo justo para dar retroalimentación (menos de 1,5 s), se acompaña de un mensaje que leen los lectores de pantalla (aria-live) y desaparece si el sistema pide reducir el movimiento.

Elige el color del texto y del fondo. El laboratorio calcula la razón de contraste de WCAG y, si no llega, te propone el color más parecido que sí cumple.

colorL = window.Lab.color
viewof cTexto = colorL("Color del texto", {value: "#ffffff"})
viewof cFondo = colorL("Color del fondo", {value: "#6bcb77"})
{
  const hex = (h) => [1, 3, 5].map((i) => parseInt(h.slice(i, i + 2), 16));
  const lin = (c) => { c /= 255; return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4); };
  const lum = (h) => { const [r, g, b] = hex(h).map(lin); return 0.2126 * r + 0.7152 * g + 0.0722 * b; };
  const razon = (a, b) => { const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p); return (x + 0.05) / (y + 0.05); };
  const mezcla = (h, d, t) => "#" + hex(h).map((c, i) => Math.round(c + (d[i] - c) * t).toString(16).padStart(2, "0")).join("");
  const r = razon(cTexto, cFondo);
  const ok = (v) => v ? "✓ cumple" : "✗ no cumple";
  let sugerencia = "";
  if (r < 4.5) {
    const cand = [];
    for (const destino of [[0, 0, 0], [255, 255, 255]]) for (let t = 0.02; t <= 1.0001; t += 0.02) { const c = mezcla(cTexto, destino, t); if (razon(c, cFondo) >= 4.5) { cand.push([t, c]); break; } }
    cand.sort((a, b) => a[0] - b[0]);
    if (cand.length) sugerencia = `<p>Propuesta para el texto: <code>${cand[0][1]}</code> (contraste ${razon(cand[0][1], cFondo).toFixed(2).replace(".", ",")}:1). <span style="display:inline-block;padding:.15rem .6rem;border-radius:6px;background:${cFondo};color:${cand[0][1]}">Así se vería</span></p>`;
    else sugerencia = "<p>Con este fondo ningún color de texto llega a 4,5:1: cambia el fondo.</p>";
  }
  const d = html`<div role="status" aria-live="polite"></div>`;
  d.innerHTML = `<div style="background:${cFondo};color:${cTexto};padding:1rem 1.25rem;border-radius:10px;border:1px solid var(--bs-border-color)"><div style="font-size:24px;font-weight:600">Sala 2.14 disponible</div><div style="font-size:16px">Máximo 2 horas al día.</div></div>
  <p class="mt-2"><strong>Contraste ${r.toFixed(2).replace(".", ",")}:1</strong></p>
  <table class="table table-sm"><thead><tr><th scope="col">Uso</th><th scope="col">Mínimo AA</th><th scope="col">Resultado</th></tr></thead><tbody>
  <tr><td>Texto normal</td><td>4,5:1</td><td>${ok(r >= 4.5)}</td></tr><tr><td>Texto grande (≥ 24 px, o 18,5 px en negrita)</td><td>3:1</td><td>${ok(r >= 3)}</td></tr><tr><td>Iconos, bordes y elementos de interfaz</td><td>3:1</td><td>${ok(r >= 3)}</td></tr><tr><td>Texto normal, nivel AAA</td><td>7:1</td><td>${ok(r >= 7)}</td></tr></tbody></table>${sugerencia}`;
  return d;
}

Elige cuatro colores para las categorías de un gráfico o los estados de la interfaz y mira cómo los perciben las personas con los tres tipos principales de daltonismo. La simulación usa el modelo de Machado, Oliveira y Fernandes (2009).

viewof p1 = colorL("Color 1", {value: "#2e7d32"})
viewof p2 = colorL("Color 2", {value: "#c62828"})
viewof p3 = colorL("Color 3", {value: "#1565c0"})
viewof p4 = colorL("Color 4", {value: "#ef6c00"})
{
  const M = {"Visión típica": null,
    "Protanopía (rojo)": [[0.152286, 1.052583, -0.204868], [0.114503, 0.786281, 0.099216], [-0.003882, -0.048116, 1.051998]],
    "Deuteranopía (verde)": [[0.367322, 0.860646, -0.227968], [0.280085, 0.672501, 0.047413], [-0.01182, 0.04294, 0.968881]],
    "Tritanopía (azul)": [[1.255528, -0.076749, -0.178779], [-0.078411, 0.930809, 0.147602], [0.004733, 0.691367, 0.3039]]};
  const lin = (c) => { c /= 255; return c <= 0.04045 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4); };
  const gam = (c) => { c = Math.min(1, Math.max(0, c)); return Math.round(255 * (c <= 0.0031308 ? 12.92 * c : 1.055 * Math.pow(c, 1 / 2.4) - 0.055)); };
  const aLin = (h) => [1, 3, 5].map((i) => lin(parseInt(h.slice(i, i + 2), 16)));
  const sim = (h, m) => { const v = aLin(h); if (!m) return v; return m.map((f) => Math.min(1, Math.max(0, f[0] * v[0] + f[1] * v[1] + f[2] * v[2]))); };
  const aHex = (v) => "#" + v.map((c) => gam(c).toString(16).padStart(2, "0")).join("");
  const oklab = ([r, g, b]) => { const l = Math.cbrt(0.4122214708 * r + 0.5363325363 * g + 0.0514459929 * b), m = Math.cbrt(0.2119034982 * r + 0.6806995451 * g + 0.1073969566 * b), s = Math.cbrt(0.0883024619 * r + 0.2817188376 * g + 0.6299787005 * b);
    return [0.2104542553 * l + 0.793617785 * m - 0.0040720468 * s, 1.9779984951 * l - 2.428592205 * m + 0.4505937099 * s, 0.0259040371 * l + 0.7827717662 * m - 0.808675766 * s]; };
  const dist = (a, b) => 100 * Math.hypot(...oklab(a).map((x, i) => x - oklab(b)[i]));
  const cols = [p1, p2, p3, p4];
  let filas = "", peor = [Infinity, "", 0, 0];
  for (const [nombre, m] of Object.entries(M)) {
    const v = cols.map((c) => sim(c, m));
    for (let i = 0; i < 4; i++) for (let j = i + 1; j < 4; j++) { const d = dist(v[i], v[j]); if (d < peor[0]) peor = [d, nombre, i + 1, j + 1]; }
    filas += `<tr><th scope="row" class="small">${nombre}</th>${v.map((x, i) => `<td><span style="display:inline-block;width:56px;height:32px;border-radius:6px;background:${aHex(x)};border:1px solid var(--bs-border-color)" role="img" aria-label="Color ${i + 1} simulado: ${aHex(x)}"></span></td>`).join("")}</tr>`;
  }
  const msg = peor[0] < 8 ? `⚠ Los colores ${peor[2]} y ${peor[3]} casi no se distinguen en ${peor[1].toLowerCase()} (diferencia ${peor[0].toFixed(1).replace(".", ",")}). Cambia la luminosidad de uno de ellos o añade otra codificación: etiqueta, icono o textura.` : `✓ La pareja más parecida (${peor[2]} y ${peor[3]}, en ${peor[1].toLowerCase()}) tiene una diferencia de ${peor[0].toFixed(1).replace(".", ",")}: se distinguen. Aun así, no uses el color como única señal.`;
  const d = html`<div role="status" aria-live="polite"></div>`;
  d.innerHTML = `<table class="table table-sm align-middle"><thead><tr><th scope="col">Visión</th>${cols.map((_, i) => `<th scope="col">${i + 1}</th>`).join("")}</tr></thead><tbody>${filas}</tbody></table><p>${msg}</p><p class="small">Diferencia: distancia en el espacio OKLab ×100. Por debajo de 8, dos colores se confunden con facilidad.</p>`;
  return d;
}

Para ver y seguir aprendiendo

Son enlaces, no vídeos incrustados: el vídeo se abre en la web de quien lo publica, así esta página no carga rastreadores de terceros. La mayoría está en inglés; activa los subtítulos si los necesitas.

  • Web Accessibility Perspectives — W3C WAI. Diez vídeos de alrededor de un minuto (contraste, teclado, subtítulos, diseño claro…), con audiodescripción y subtítulos.
  • Video Introduction to Web Accessibility and W3C Standards — W3C WAI. Cuatro minutos sobre qué es la accesibilidad web y qué son las WCAG.
  • 5 Tips for New Prototypers — Nielsen Norman Group. Consejos de diseño y de flujo de trabajo para prototipos que se van a probar con usuarios.

Para tu proyecto

  • Copia la tabla de tokens de la escala tipográfica a tu sistema de diseño.
  • Especifica los seis estados de cada componente interactivo, como en la tabla del botón.
  • Haz siempre una versión «antes y después» para justificar tus decisiones en la crítica.
  • Pasa todos los pares texto-fondo por el comprobador de contraste y la paleta de tus gráficos por el simulador de daltonismo.
